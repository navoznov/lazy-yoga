# Lazy Yoga — спецификация

Личный помощник для ежедневной короткой практики йоги: сам собирает программу на день и ведёт по ней голосом, чтобы не нужно было помнить позы.

## Пользователь

- Только автор, одно устройство, без аккаунтов.
- Новичок, 42 года, **повышенное давление**, сидячая работа программистом, плохая гибкость (не достаёт до носков).
- Цели: спина, шея, бёдра, общая гибкость.

## Платформа

- PWA: Vite + TypeScript + Preact.
- Хостинг: GitHub Pages.
- Без бэкенда; состояние (история, прогрессия, флаг дисклеймера) — в `localStorage`.

## Сессия

- 10–15 минут, ежедневно.
- Старт в один тап: при открытии программа на сегодня уже собрана, одна кнопка «Начать».
- Коротких режимов, напоминаний и streak нет — сознательно.

## База поз

- Составляется вручную (Claude), 25–35 мягких поз для новичка.
- Поля позы: id, русское название, санскрит (только для экрана), описание, голосовые подсказки (1–2 на вход), время удержания, двусторонняя ли поза, положение (стоя/сидя/лёжа/на стуле), теги (зоны тела, сложность), противопоказания, ключ yoga_api (если есть), промпт для генерации картинки.
- Значения консервативные: удержание 20–45 с.
- Базу стоит один раз показать врачу или инструктору.

## Фильтр по давлению (жёсткий, не отключается, покрыт тестами)

Исключаются:
- перевёрнутые позы (стойка на голове/плечах, плуг);
- позы с головой ниже сердца дольше 15–20 с;
- задержки дыхания и форсированное дыхание (капалабхати);
- интенсивные прогибы и статические силовые позы (долгая планка, стульчик).

При первом запуске — одноразовый дисклеймер «согласуй нагрузку с врачом».

## Генератор программы

- Rule-based, без LLM.
- Структура: разминка → основная часть → расслабление.
- Двусторонние позы автоматически разбиваются: правая сторона → «смена стороны» → левая.
- Переход между позами 7–10 с; переход из положения лёжа в положение стоя — дольше (или такие позы не ставятся рядом).

## Прогрессия

- Первые 2–3 недели база программы почти не меняется — повторение помогает запоминать.
- Дальше удержания постепенно растут.
- После сессии оценка «легко / нормально / тяжело» корректирует нагрузку.

## Голос

- Заранее сгенерированные аудиофайлы, Yandex SpeechKit.
- Реплики: название позы, 1–2 подсказки по технике, «дыши спокойно» на середине удержания, «ещё 10 секунд» перед концом, служебные фразы («смена стороны», «следующая поза…»).
- Скрипт генерации в репозитории; файлы адресуются хэшем текста — перегенерируются только изменённые фразы.
- API-ключ — из переменной окружения, в репозиторий не попадает.

## Картинки

- MVP: SVG-иконки из [yoga_api](https://github.com/rebeccaestes/yoga_api) (авторы — Claire Jones, Elizabeth Sobka, Noun Project; предположительно CC BY — проверить), скачанные и хостящиеся локально, страница с авторами.
- Позы без иконки (на стуле, шея/плечи, скрутка лёжа, ноги на стене, гора) — только текст.
- Следующий шаг: генерация картинок через OpenAI или Gemini по промптам из базы, минималистичный силуэт в одежде, ручная проверка на брак.
- Без обнажённой натуры.

## Во время практики

- Экран не гаснет (Wake Lock API).
- Управление жестами по всему экрану: тап — пауза/продолжить, свайп — пропустить позу.

## Процесс

- Работа в отдельных ветках, в `main` — только через PR.
